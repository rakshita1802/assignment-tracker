# 📚 Assignment Tracker System

A Java-based desktop application designed to help teachers manage assignments and track student submissions efficiently.

---

## 🚀 Features

### 👨‍🏫 Teacher Module
- Create and manage assignments
- View student submissions
- Open uploaded files
- Grade submissions with marks and feedback

### 👩‍🎓 Student Module
- View assigned tasks
- Upload assignment files
- Add comments while submitting

### 🔐 Authentication
- Secure login system
- Forgot password functionality with email support

---

## 🛠️ Tech Stack

- **Java (Swing)** – UI Development
- **SQLite** – Database
- **JDBC** – Database connectivity
- **IntelliJ IDEA** – Development environment
